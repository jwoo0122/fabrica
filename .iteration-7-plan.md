## Proposed new AC

### AC-1.16 — NodeId(0) collision guard (INC-3 scope)

**Text (inserted into `.iteration-7-criteria.md` §1 after AC-1.15):**

> AC-1.16: `flatten_recursive` must never return `NodeId(0)` for any non-root node. Two evidences:
> (a) **Grep** — the implementation contains an explicit collision guard. `grep -nE 'if (id|hashed|h) == 0' sdui-core/src/lib.rs | wc -l` ≥ 1 **or** `grep -nE '\.max\(1\)' sdui-core/src/lib.rs | wc -l` ≥ 1 (either shape of the zero→one collapse is acceptable).
> (b) **Unit test** — a test named `hash_never_produces_zero_for_keyed_nodes` (or `root_reserved_is_never_reused_for_child`) exists in `sdui-core/tests/identity.rs` and passes. `grep -nE 'fn hash_never_produces_zero|fn root_reserved_is_never_reused' sdui-core/tests/identity.rs | wc -l` ≥ 1.
> `cargo test -p sdui-core --test identity hash_never_produces_zero_for_keyed_nodes` (or alternate) exit 0.

**Rationale:** §T-2 line 269 said "0 이면 1 로 치환" but never lifted to an AC. Promoting closes the gap.

Hybrid (VER concern #5):

- **Per-INC** for scope-local ACs (preferred protocol).

- **Preflight (AC-12.1)** registered as gating precondition; run at start of every `/verify-*`.
- **Platform gating:** macOS-only ACs carry `platform=macos` metadata; non-matching hosts skip+warn.
